# CoEditor

> **人类是主笔，AI 是编辑。** —— AI 辅助写作工具，帮你把稿子写得更好，但永远不替你做决定。

[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

CoEditor 是面向**小说、网文与长篇创作**的 AI 辅助写作工具。它像一位随叫随到的资深编辑：审阅你的文稿、指出问题、给出可落地的修改建议——而你始终掌握笔，自己决定每一处改动。

一套代码同时支持 **PC / 浏览器（H5）** 与**微信小程序**，并提供 **macOS 桌面版**，数据完全属于你。

---

## 它能做什么

写作时最缺的，是一个能通读全文、记得住人设和世界观、随叫随到的编辑。CoEditor 把这件事交给 AI，但把创作主动权留给你：

- **分段审阅**：选中一段文字，AI 以编辑视角点评——节奏、逻辑、表达，并给出修改示例，你自己决定改不改。
- **整章 / 全文审阅**：不只是看一句一段，而是从整体结构、人物弧光、情节推进的层面给你意见。
- **附件一起看**：大纲、世界观、人设、人物关系等设定材料自动带入审阅上下文，AI 不会"忘了谁是谁"。
- **三种编辑风格**：严厉、温和、鼓励——今天想被鞭策还是想被夸，随时切换。
- **看得到思考过程**：AI 的推理过程可以折叠展开，结论不再"从天而降"，可追溯、可信任。

## 亮点

- **为长篇而生**：小说模板内置大纲 / 世界观 / 人设 / 人物关系四类设定附件，每类都单独维护、单独可审，长文不散架。
- **版本历史**：每次保存都留一个版本，随时回到任意历史稿——写岔了也不慌。
- **流式实时输出**：AI 边想边写逐字呈现，可中止、可重试、可对比多个候选答案。
- **私密自托管**：你的文稿与 API Key 都存在**自己本机**的服务端，不上传任何第三方；自带 AI 配置兼容 DeepSeek / OpenAI / Ollama 等一切 OpenAI 协议端点。
- **响应式 & 夜间模式**：PC 三栏布局可拖拽调整；手机竖排滚动 + 侧滑目录；深色模式跟随系统。

## 快速开始

### 方式一：桌面版（推荐，开箱即用）

macOS 桌面版内置本地服务与全部依赖，无需任何配置，下载安装即可开始写作。

### 方式二：本地运行

需要 Node.js ≥ 20.11 与 [pnpm](https://pnpm.io/)：

```bash
pnpm install
pnpm dev        # 同时启动服务与前端
```

浏览器打开 `http://localhost:5173`，在右上角设置中填入你的 API Key（支持 DeepSeek / OpenAI / Ollama 等任意 OpenAI 协议服务），即可开始。

### 方式三：微信小程序

构建后导入微信开发者工具即可使用（API 指向你自己的服务端地址）。

---

## 你的数据，你的

- 文稿与 API Key 默认都存储在**你自己电脑的本地**，无云同步、无账号体系，关掉浏览器数据也还在。
- 一切以你为准：只有当你**主动提交某段文字给 AI 审阅**时，相关内容才会发送给你自己配置的模型服务商（如 DeepSeek / OpenAI）；其余时间数据不离开本机。
- 想迁移数据？导出目录即可整体带走。
